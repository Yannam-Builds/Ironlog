# Exercise library management parity

Settings now opens a separate exercise-library route instead of a dismiss-on-pick chooser. It follows Kotlin ExerciseLibraryScreen: All/Favorites/Custom and BW-only scopes, removable active chips, a filter sheet for muscles/equipment/category/movement/difficulty, 180 ms search, gym equipment exclusion, favorite-first/name ordering, recently completed exercise search chips and row navigation to progress. It uses Compose star/filter/delete paths, 72px minimum rows, 44px controls, shared themes and sheet/route transitions.

All results are accessible. Web renders 100 at a time with Show more instead of Android's LazyColumn virtualization. Creation reuses the existing custom form with unmatched query prefilled; saving retains the library destination. Editing and tutorial links remain follow-up work; no new native tracking editor has been assumed.

Favorites persist in the profile and canonical native favorite_exercises JSON setting, including double-encoded older JSON. Native settings override stale web-extension favorites during import. Each favorite mutation reads the current profile in a write transaction. Custom creation validates normalized duplicate names within its transaction, preventing simultaneous creates from duplicating a movement. Existing catalog overrides and recorded snapshots retain their behavior.

Confirmed custom deletion protects built-ins, plan references and every workout status, including imported name-only references. Deletion, restored-catalog removal, favorite cleanup and reminder cleanup commit together. Referenced or failed writes keep the exercise and show the failure within the confirmation sheet. A removed restored custom exercise cannot return on bootstrap.

Verification: 53 files / 263 unit tests, TypeScript/build and 185-file output checks. Tests cover concurrent duplicate creation/favorites, native and browser backup transfer, reference protection, transaction rollback, restored entry deletion, actual Settings navigation, filters, creation/confirmation/error behavior, recent names and results past the old limit. Isolated Chrome at 320px verifies favorite reload, filter scopes, creation/reload/cancel/delete, 200 accessible rows, progress/back origins and no horizontal overflow. Screenshots under ignored web/output/playwright/library*.png. Zero console errors/warnings.
