# IronLog 0.1.0 Pre-Alpha 1

This is the first public pre-alpha build of IronLog. It is intended for hands-on testing and feedback, not production training records without a separate backup.

## Highlights

- Rebuilt onboarding with a clearer fast path, an IronLog-native visual system, and explicit links between setup choices and programming, recovery, streaks, badges, widgets, and the Iron Ledger.
- Added iPhone-style infinite, center-snapping wheels for onboarding numeric inputs, including body weight, birth year, training age, weekly training history, and optional movement baselines.
- Kept gamification evidence-based: onboarding creates provisional calibration and RPG stats, while XP and permanent grade progress still require verified workouts.
- Deferred Android permission prompts until the athlete explicitly requests the related benefit.
- Refined starter-plan cards and the calibration summary for better hierarchy and smaller-screen readability.
- Fixed the Health Connect prompt so it expands and scrolls within the viewport.

## Pre-alpha notes

- Back up important data before testing upgrades or imports.
- Cloud AI requires the tester's own compatible provider key and remains optional.
- Health Connect availability and supported records depend on the Android device and installed provider.
- Please report the screen, action, device model, Android version, and reproduction steps with any issue.
